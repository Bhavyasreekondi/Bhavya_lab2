# Evaluation Files

This folder contains the evaluation data for all three lab parts.

- `golden_questions.csv`: Questions with expected sources and keywords.
- `expected_answers.json`: Ground-truth answer requirements.
- `scenarios.json`: Normal Part 3 evaluation scenarios.
- `red_team_cases.json`: Safety and refusal tests.
- `human_evaluation_template.csv`: Template for human ratings.

Evaluation outputs should be saved in the `traces/` folder.
