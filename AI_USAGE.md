# AI Usage Disclosure

Generative AI tools were used as a coding and writing assistant. Assistance included explaining Python and notebook syntax, diagnosing dependency and runtime errors, improving sentence clarity, suggesting retrieval and evaluation code, and organizing repository documentation.

All generated code was reviewed, adapted, executed, and checked by the team. Model outputs were not treated as evidence for the knowledge base. The final answers were grounded in the provided documents and the final evaluation results were produced by the executed notebooks.

Example prompts included:

- Explain this Python error and provide a compatible fix.
- Improve the hybrid dense-plus-BM25 retrieval function while preserving the required submission format.
- Check that this CSV contains the required columns, row count, and valid statuses.
- Organize the lab artifacts into a reproducible GitHub repository structure.
